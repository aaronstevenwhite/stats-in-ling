Problem Set 5: Structure in phoneme inventories

  • Show All Code
  • Hide All Code
  • View Source

Statistical Methods in Linguistics

What this problem set asks

Languages do not assemble their phoneme inventories by choosing each segment in isolation. A language with one series of voiced stops may be more likely to have other members of that series. Vowel length may recur across several vowel qualities. Place contrasts may likewise extend across several manners of articulation. These examples suggest that segment presence has structure.

The comparison baseline predicts whether a segment occurs in an inventory using only the overall prevalence of that segment. It does not use the other segments in the inventory. A low rank representation can improve on this prevalence-only baseline only if recurring configurations of segments contain information about a cell that we deliberately hide.

The focal technique is a low-rank approximation based on the singular value decomposition. We will represent languages by segments, hide a balanced set of present and absent cells, select the rank on validation cells, and evaluate the selected representation on separate test cells. Following the earlier definition of predictive loss, the improvement in reconstruction is the baseline Brier loss minus the low-rank Brier loss:

\operatorname{improvement} = \operatorname{Brier}_{\text{prevalence}} - \operatorname{Brier}_{\text{low rank}}.

A positive improvement means that the low rank representation reconstructs held out cells better than segment prevalence alone. It does not show that the components are universal phonological dimensions. We will need the inventory source, language family, and macroarea diagnostics to determine how much structure those labels carry.

NoteData documentation

Consult the PHOIBLE 2.0 download and citation page and the FAQ sections “Why do some languages have multiple entries in PHOIBLE?”, “Random sampling: one inventory per isocode/glottocode”, and “What are the different sources in PHOIBLE?”. This documentation is included because the row selection and source diagnostic depend on how PHOIBLE combines inventories from different descriptions and collections. The factorization cannot be interpreted before those sampling decisions are understood.

Before beginning, review linguistic data matrices, centering and scaling, rank one structure, singular value decomposition, principal component analysis, scores and loadings, reconstruction, and choosing components. Each page supplies one part of the analysis below. The low-rank approximation is the only focal technique introduced here. Masking and scoring apply the training, validation, and test separation used earlier in the course.

Prepare the data

The archived release is Moran and McCloy’s (2019) PHOIBLE 2.0, DOI 10.5281/zenodo.2593234. The PHOIBLE site licenses the data under Creative Commons Attribution ShareAlike 3.0 Unported. The course does not commit a copy of the archive.

From the repository root, run:

Rscript problem-sets/ps5/scripts/prepare-phoible.R

The script downloads the pinned CLDF archive, checks its MD5 and SHA 256 values, and creates data/phoible-pilot.rds inside the PS5 directory. It retains consonants and vowels, removes tones, and removes rows explicitly marked as marginal. A blank marginality field remains because it means that the source did not state whether the segment is marginal.

Load the prepared object and the audited functions.

Code 
phoible <- readRDS("data/phoible-pilot.rds")
source("scripts/phoible-svd-functions.R")

names(phoible)
phoible$provenance

The object contains three linked tables.

  1. memberships: one row states that one segment occurs in one contributed inventory.
  2. inventories: one row describes one contributed inventory and its Glottocode, source collection, top level family, and macroarea.
  3. segments: one row describes one PHOIBLE segment parameter.

The inventory source is the PHOIBLE collection that contributed a description, not the language’s family or location. Several collections have restricted geographic coverage. Thus source, family, and macroarea may be associated with one another.

Task 3: construct the language by segment matrix (10 points)

We now turn the membership table into a binary matrix. A row is a selected inventory. A column is a PHOIBLE segment. A cell equals one when that segment occurs in the selected inventory and zero otherwise.

Very rare segment columns create two problems for this exercise. First, a segment seen only once or twice supplies too little information for held out reconstruction. Second, a large set of nearly empty columns makes the result depend on many source specific transcription decisions. The primary analysis thus retains a segment only if it occurs in at least 20 selected inventories.

Task 4: hide balanced present and absent cells (10 points)

If we scored every cell, an algorithm that always predicts zero would appear accurate because almost 90 percent of the matrix is zero. Such a score would say little about recovering segments that are actually present. We will thus mask equal numbers of present and absent cells.

For every eligible inventory, reserve three present and three absent cells for validation. Then reserve a disjoint set of three present and three absent cells for testing. An inventory is eligible when it has at least ten present and ten absent cells. The cells are known in the source data. They are hidden only to evaluate reconstruction.

Code 
masks <- make_balanced_masks(X, seed = 20260847L)

sum(masks$eligible)

sum(masks$test)
sum(masks$validation & masks$test)
table(X[masks$validation])
table(X[masks$test])

Piloted checkpoint: all 2,186 inventories are eligible. Validation and test each contain 13,116 cells, split equally between presence and absence, with no overlap.

Task 5: define the prevalence baseline (10 points)

The baseline uses the observed training prevalence of segment j,

\widehat p_j = \frac{\text{observed inventories containing segment }j} {\text{inventories observed for segment }j}.

The same value is predicted for every hidden cell in column j. Thus the baseline knows that /m/ is common and a rarer segment is rare, but it cannot use the rest of a particular inventory.

Hide both validation and test cells. Estimate the column means from the remaining cells, and predict each validation cell with its column mean.

Code 
validation_training <- X
validation_training[masks$validation | masks$test] <- NA_real_

segment_prevalence <- colMeans(validation_training, na.rm = TRUE)
validation_cells <- which(masks$validation, arr.ind = TRUE)
validation_baseline <- segment_prevalence[validation_cells[, "col"]]
validation_truth <- X[masks$validation]

balanced_score(validation_truth, validation_baseline, loss = "brier")

For a binary cell with observed value y and prediction p, Brier loss is (y-p)^2. The balanced score takes the mean loss for present cells and absent cells separately, then averages those two means. Write out this calculation using the validation vectors and verify that it matches balanced_score().

Explain why column prevalence is a more informative baseline than the constant value .5, even though the evaluation set is balanced.

Piloted checkpoint: validation balanced Brier loss for the prevalence-only baseline is .2168.

Task 6: select the rank on validation cells (15 points)

The low rank model begins with the same column means. After centering, a hidden cell is filled with zero on the centered scale, which is equivalent to filling it with its column mean on the original scale. We then compute

\mathbf{X}_{c} = \mathbf{U}\mathbf{D}\mathbf{V}^{\mathsf T}.

At rank K, the reconstruction for cell (i,j) is

\widehat x_{ij,K} = \widehat p_j + \sum_{k=1}^{K}d_k u_{ik}v_{jk}.

The first term is the prevalence-only baseline. Each additional term uses a row score and a segment loading to adjust that baseline. Predictions below zero or above one are clipped to the unit interval because the cells are binary.

We center each segment column but do not divide it by its standard deviation. Standardizing a binary column would give a rare segment a different weight from the one it has in cellwise Brier loss. The unscaled factorization thus matches the reconstruction target stated above. This is a modeling decision, not a general prohibition against scaling binary variables.

Fit up to rank 40 while both validation and test cells are hidden. Score the declared candidate ranks on validation cells.

Code 
candidate_ranks <- c(1L, 2L, 3L, 5L, 8L, 12L, 16L, 24L, 32L, 40L)

Task 7: evaluate once on the test cells (10 points)

The rank is now fixed. Restore the validation cells, keep only the test cells hidden, and recompute the factorization. This refit uses the validation values as training information without allowing the test values to determine the component directions.

Task 8: inspect phonological and database structure (15 points)

Good reconstruction establishes cooccurrence structure. It does not tell us what generated that structure. We will inspect segment loadings and three labels attached to each selected inventory.

Describe one recurring phonological pattern in each table. For component 1, attend to the contrast between several plain obstruents and several retroflex or dental segments. For component 2, attend to long vowels. Because component signs are arbitrary, write about segments loading on the same or opposite sides, not about an inherently positive component.

Next, calculate component scores and their association with source, top level family, and macroarea. For a score vector z and grouping g, the squared correlation ratio, also called eta squared in a one-way analysis, is

\eta^2(z,g) = \frac{\sum_h n_h(\overline z_h-\overline z)^2} {\sum_i(z_i-\overline z)^2}.

It measures the proportion of observed score variation lying between the named groups. For the family calculation, families with fewer than 15 selected inventories are combined into Other small families. Without this grouping, a family represented by one inventory would place all of that inventory’s score variation between families by construction. The ratio is not a causal effect, and it does not identify which of the three associated labels generated the pattern.

LING 414 extension: determine what the first component predicts

Component 1 is strongly associated with source, family, and macroarea. These labels are themselves associated. Construct three descriptive predictions of the component 1 score, one from each label, using leave-one-inventory-out group means. For an omitted inventory, predict its score with the mean of the remaining inventories in the same group, falling back to the overall training mean when the group has no remaining member.

Compare squared prediction loss for source, family, and macroarea. This comparison asks which label transfers most information about this fitted score under a particular grouping rule. It does not isolate a causal contribution and must not be described as controlling for the other labels.

Submission checklist

  1. The analysis runs from a fresh R session after the data preparation command.
  2. Exactly one inventory is selected per Glottocode.
  3. The matrix meaning and rare segment threshold are stated before factorization.
  4. Validation and test masks contain equal numbers of present and absent cells and do not overlap.
  5. Rank is selected without using test cells.
  6. Test results are evaluated once after rank selection.
  7. Loading signs are treated as arbitrary.
  8. Source, family, and macroarea diagnostics appear before the final claim.
  9. Sensitivity conditions change only the declared selection rule and rare segment threshold.

## Prepare the data

The archived release is Moran and McCloy's (2019) PHOIBLE 2.0, DOI [10.5281/zenodo.2593234](https://doi.org/10.5281/zenodo.2593234). The PHOIBLE site licenses the data under Creative Commons Attribution ShareAlike 3.0 Unported. The course does not commit a copy of the archive.

From the repository root, run:

```sh
Rscript problem-sets/ps5/scripts/prepare-phoible.R
```

The script downloads the pinned CLDF archive, checks its MD5 and SHA 256 values, and creates `data/phoible-pilot.rds` inside the PS5 directory. It retains consonants and vowels, removes tones, and removes rows explicitly marked as marginal. A blank marginality field remains because it means that the source did not state whether the segment is marginal.

Load the prepared object and the audited functions.

```{r}
phoible <- readRDS("data/phoible-pilot.rds")
source("scripts/phoible-svd-functions.R")

names(phoible)
phoible$provenance
```

The object contains three linked tables.

1. `memberships`: one row states that one segment occurs in one contributed inventory.
2. `inventories`: one row describes one contributed inventory and its Glottocode, source collection, top level family, and macroarea.
3. `segments`: one row describes one PHOIBLE segment parameter.

The inventory source is the PHOIBLE collection that contributed a description, not the language's family or location. Several collections have restricted geographic coverage. Thus source, family, and macroarea may be associated with one another.

## Task 3: construct the language by segment matrix (10 points)

We now turn the membership table into a binary matrix. A row is a selected inventory. A column is a PHOIBLE segment. A cell equals one when that segment occurs in the selected inventory and zero otherwise.

Very rare segment columns create two problems for this exercise. First, a segment seen only once or twice supplies too little information for held out reconstruction. Second, a large set of nearly empty columns makes the result depend on many source specific transcription decisions. The primary analysis thus retains a segment only if it occurs in at least 20 selected inventories.

## Task 4: hide balanced present and absent cells (10 points)

If we scored every cell, an algorithm that always predicts zero would appear accurate because almost 90 percent of the matrix is zero. Such a score would say little about recovering segments that are actually present. We will thus mask equal numbers of present and absent cells.

For every eligible inventory, reserve three present and three absent cells for validation. Then reserve a disjoint set of three present and three absent cells for testing. An inventory is eligible when it has at least ten present and ten absent cells. The cells are known in the source data. They are hidden only to evaluate reconstruction.

```{r}
masks <- make_balanced_masks(X, seed = 20260847L)
```

## Task 5: define the prevalence baseline (10 points)

The baseline uses the observed training prevalence of segment $j$,

$$
\widehat p_j
=
\frac{\text{observed inventories containing segment }j}
{\text{inventories observed for segment }j}.
$$

The same value is predicted for every hidden cell in column $j$. Thus the baseline knows that /m/ is common and a rarer segment is rare, but it cannot use the rest of a particular inventory.

Hide both validation and test cells. Estimate the column means from the remaining cells, and predict each validation cell with its column mean.

```{r}
validation_training <- X
validation_training[masks$validation | masks$test] <- NA_real_

segment_prevalence <- colMeans(validation_training, na.rm = TRUE)
validation_cells <- which(masks$validation, arr.ind = TRUE)
validation_baseline <- segment_prevalence[validation_cells[, "col"]]
validation_truth <- X[masks$validation]

balanced_score(validation_truth, validation_baseline, loss = "brier")
```

For a binary cell with observed value $y$ and prediction $p$, Brier loss is $(y-p)^2$. The balanced score takes the mean loss for present cells and absent cells separately, then averages those two means. Write out this calculation using the validation vectors and verify that it matches `balanced_score()`.

Explain why column prevalence is a more informative baseline than the constant value .5, even though the evaluation set is balanced.

**Piloted checkpoint:** validation balanced Brier loss for the prevalence-only baseline is .2168.

## Task 6: select the rank on validation cells (15 points)

The low rank model begins with the same column means. After centering, a hidden cell is filled with zero on the centered scale, which is equivalent to filling it with its column mean on the original scale. We then compute

$$
\mathbf{X}_{c}
=
\mathbf{U}\mathbf{D}\mathbf{V}^{\mathsf T}.
$$

At rank $K$, the reconstruction for cell $(i,j)$ is

$$
\widehat x_{ij,K}
=
\widehat p_j
+
\sum_{k=1}^{K}d_k u_{ik}v_{jk}.
$$

The first term is the prevalence-only baseline. Each additional term uses a row score and a segment loading to adjust that baseline. Predictions below zero or above one are clipped to the unit interval because the cells are binary.

We center each segment column but do not divide it by its standard deviation. Standardizing a binary column would give a rare segment a different weight from the one it has in cellwise Brier loss. The unscaled factorization thus matches the reconstruction target stated above. This is a modeling decision, not a general prohibition against scaling binary variables.

Fit up to rank 40 while both validation and test cells are hidden. Score the declared candidate ranks on validation cells.

Next, calculate component scores and their association with source, top level family, and macroarea. For a score vector $z$ and grouping $g$, the squared [**correlation ratio**](https://courses.washington.edu/psy524a/_book/anova-is-just-regression.html), also called eta squared in a one-way analysis, is

$$
\eta^2(z,g)
=
\frac{\sum_h n_h(\overline z_h-\overline z)^2}
{\sum_i(z_i-\overline z)^2}.
$$

It measures the proportion of observed score variation lying between the named groups. For the family calculation, families with fewer than 15 selected inventories are combined into `Other small families`. Without this grouping, a family represented by one inventory would place all of that inventory's score variation between families by construction. The ratio is not a causal effect, and it does not identify which of the three associated labels generated the pattern.

