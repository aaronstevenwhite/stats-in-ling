# Pedagogy graphs for Modules 1–3

These artifacts encode the instructional sequence at three levels: module, page or
document, and content block or slide. Each source node records an exact file and line
span. Directed `NEXT` edges preserve reading order, while typed edges such as
`CONTAINS`, `CANONICAL_NEXT_PAGE`, and `REALIZED_AS` distinguish hierarchy,
canonical sequence, and note-to-slide realization.

- `reference-notes-style-and-pedagogy.json` contains the wording, sentence, paragraph,
  and rhetorical profile of the three reference notes, together with their block-level
  graph and recurring pedagogical motifs.
- `course-modules-1-3-pedagogy-graph.json` contains the block-level graph for the first
  three revised course modules and the slide graph for each corresponding Reveal deck.
- `course-modules-1-3-pedagogy-graph-before-revision.json` preserves the same graph
  extracted from `git HEAD`, before this repair, so the comparison is auditable rather
  than reconstructed from memory.
- `reference-course-alignment.json` records the comparison and the minimal
  transformation used in the revision.
- `alignment-check.json` is generated by `scripts/check_module_alignment.py` and
  records page-order, terminology, notation, and slide-density checks.

Every graph node includes `layout.rank`, `layout.x`, and `layout.y`. A graph viewer can
use those values as an initial layered layout or recompute positions from the typed
edges. Rebuild the four graph artifacts with:

```sh
python3 scripts/build_pedagogy_graphs.py
```

Then check note-to-slide alignment with:

```sh
python3 scripts/check_module_alignment.py
```
