# Pedagogy audits and reference profile

This directory contains the evidence used to revise the course notes as a
self-contained teaching resource.

- `reference-notes-style-and-pedagogy.json` records the wording, sentence,
  paragraph, and rhetorical profile of the three reference notes.
- `audit-foundations-random-variables.md` audits all foundations and
  random-variable pages.
- `audit-statistical-inference-experimental-design.md` audits all inference and
  design pages, including the detailed Provo Student-t analysis.
- `regression-models-audit.md` audits all linear, generalized, and mixed-model
  pages.
- `audit-model-criticism-latent-structure.md` audits all prediction and
  latent-structure pages.
- `audit-factorization-missing-custom.md` audits all factorization, missing-data,
  and custom-model pages.

The course no longer maintains a slide layer. The audits therefore evaluate the
notes directly: concept order, first-treatment links, measurement explanations,
model-choice arguments, derivations, code bridges, interpretations, and checks.
