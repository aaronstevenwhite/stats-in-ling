# Problem Set 2: prediction across passages

This directory contains the rebuilt PS2.

- `ps2.qmd` is the student assignment.
- `ps2-answer-key.qmd` is the instructor key and is not rendered with the public site.
- `data/provo-content-word-positions.csv` is a derived teaching table.
- `scripts/prepare_data.R` reconstructs the table from the frozen Provo eye-tracking release.

The original corpus is © 2017 Steven G. Luke and Kiel Christianson and is available from the [Provo Corpus OSF project](https://osf.io/sjefs/) under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The teaching table filters to complete content-word positions and averages log first-fixation duration over observed readers; it is an adapted version distributed under the same license with attribution.

The scientific specification, source audit, pilot outputs, and release decision live in `research/homework-validation/ps2/`.
